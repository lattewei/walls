# Web — Walls

Landing (`/`) and app home (`/app`).

## Run

```bash
npm install
npm run dev
```

## Content

- Landing copy: `src/content/site.ts`
- App shelves / tiles: `src/content/home.ts`

## Hero background

Source art: `public/bg.jpg`  
Dithered asset used on the landing: `public/bg-dither.jpg`

Regenerate after changing the source:

```bash
npm run dither
```
